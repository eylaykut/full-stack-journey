# Day 01 — İlk HTML Sayfam

Full stack geliştirme yolculuğumun ilk gününde HTML ile kişisel bir sayfa oluşturdum.

## Öğrendiklerim
- HTML belgesinin temel yapısı
- Başlık ve paragraf etiketleri
- Madde işaretli ve numaralı listeler
- Bağlantı ve görsel ekleme
- strong ile önemli metinleri vurgulama
- Etiketleri iç içe kullanma
- header, nav, main, section ve footer ile sayfayı bölümlere ayırma
- id ve sayfa içi bağlantılarla bölümlere gitme

## Çalıştırma
index.html dosyasını tarayıcıda aç.
