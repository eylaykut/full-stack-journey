# Day 10 - Harcama Takip Uygulaması

Bu projede HTML, CSS ve JavaScript kullanarak tarayıcıda çalışan bir harcama takip uygulaması geliştirdim.

## Uygulamanın Özellikleri

- Harcama adı ve tutarı ekleme
- Boş veya geçersiz değerleri engelleme
- Harcamaları dinamik olarak listeleme
- Her harcamaya benzersiz bir ID verme
- Harcamaları tek tek silme
- Bütün harcamaları onay alarak silme
- Toplam harcama tutarını hesaplama
- Verileri Local Storage'da saklama
- Sayfa yenilendiğinde kayıtları yeniden gösterme
- Mobil ekranlara uyumlu tasarım

## Öğrendiğim ve Tekrar Ettiğim Konular

- Formlarda `submit` olayı
- `event.preventDefault()`
- Input değerlerini `.value` ile alma
- `.trim()` ile gereksiz boşlukları temizleme
- `Number()` ile metni sayıya dönüştürme
- Nesne oluşturma
- Dizilere `push()` ile eleman ekleme
- `forEach()` ile dizileri dolaşma
- `filter()` ile diziden eleman çıkarma
- `Date.now()` ile benzersiz ID oluşturma
- Fonksiyonlara bölerek kodu düzenleme
- DOM üzerinde dinamik öğe oluşturma
- Local Storage kullanımı
- `JSON.stringify()` ve `JSON.parse()`
- `alert()` ve `confirm()` kullanımı
- Responsive CSS tasarımı
