# Day 06 — Erişilebilirlik ve Kod Kalitesi

Portfolio sayfasının erişilebilirliğini ve CSS bakım kolaylığını geliştirdim.

## Öğrendiklerim

- aria-label ile navigasyonu açıklama
- Görseller için anlamlı alt metni yazma
- Klavye ile sayfa kullanımını test etme
- focus-visible ile görünür odak tasarımı
- CSS değişkenlerini :root içinde tanımlama
- var() ile ortak renkleri kullanma
- prefers-reduced-motion ile hareketleri azaltma
- div yapılarını anlamsal ul ve li etiketlerine dönüştürme
- Responsive ve erişilebilir tasarımı birlikte kullanma

## Kontroller

- Sayfa yalnızca klavyeyle kullanılabiliyor.
- Navigasyon bağlantıları ilgili bölümlere gidiyor.
- Mobil görünümde yatay taşma bulunmuyor.
- Hareket azaltma tercihi destekleniyor.
