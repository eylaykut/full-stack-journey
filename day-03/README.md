# Day 03 — CSS Box Model

CSS box model yapısını öğrenerek sayfalardaki boyutları ve boşlukları daha kontrollü hâle getirdim.

## Öğrendiklerim

- Content, padding, border ve margin
- Box-sizing: border-box kullanımı
- Evrensel seçici
- Padding ve margin kısa yazımları
- Width, max-width ve calc kullanımı
- İçeriği yatay olarak ortalama
- Div ve tekrar kullanılabilir class yapısı
- Doğrudan çocuk ve son çocuk seçicileri
- Form alanlarının boşluklarını düzenleme
- Min-height ve resize özellikleri
- Transition ile yumuşak geçiş
- Tarayıcı geliştirici araçlarında box model inceleme

## Uygulama

İletişim formuna box model özellikleri kullanılarak bir bilgilendirme kutusu eklendi.
