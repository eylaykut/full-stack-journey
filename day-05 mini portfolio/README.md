# Day 05 — Responsive Portfolio

HTML ve CSS kullanarak kişisel portfolio sayfasını sıfırdan oluşturdum.

## Özellikler

- Anlamsal HTML yapısı
- Sayfa içi navigasyon
- Hakkımda, yetenekler ve iletişim bölümleri
- Responsive CSS Grid
- Hover efektli yetenek kartları
- E-posta ve GitHub bağlantıları
- Mobil ekranlar için media query
- Yumuşak sayfa kaydırma
- Masaüstü ve mobil uyum

## Öğrendiklerim

- Bir sayfayı sıfırdan yapılandırma
- Flexbox ile navigasyon
- Grid, auto-fit ve minmax kullanımı
- Max-width ve calc ile responsive boyutlandırma
- Transform ve transition farkı
- Media query ile mobil tasarım
