# Day 08 - JavaScript Objects and Array Methods

## Bugün Öğrendiklerim

- JavaScript nesneleri oluşturma
- Nesne özelliklerine nokta ve köşeli parantez ile erişme
- Nesnelere yeni özellik ekleme ve mevcut özellikleri değiştirme
- Nesne metotları ve `this` kullanımı
- Nesnelerden oluşan diziler
- `forEach()` ile diziyi dolaşma
- `map()` ile yeni dizi oluşturma
- `filter()` ile koşula uyan elemanları seçme
- `find()` ile ilk eşleşen elemanı bulma
- Nesne verilerinden dinamik DOM öğeleri oluşturma
