# Day 02 — CSS Temelleri

HTML sayfalarımı CSS kullanarak tasarladım ve mobil görünümünü kontrol ettim.

## Öğrendiklerim

- Harici CSS dosyasını HTML'e bağlama
- Etiket, class ve iç içe CSS seçicileri
- Renk ve yazı tipi özellikleri
- CSS kalıtımı
- Padding ve margin farkı
- Border, border-radius ve box-shadow
- Hover ve focus durumları
- Görselleri ekran genişliğine uyarlama
- Form alanlarını tasarlama
- Box-sizing kullanımı
- Viewport ayarı ve geliştirici araçlarında mobil kontrol

## Dosyalar

- index.html: Tasarlanmış ana sayfa
- contact.html: Tasarlanmış iletişim formu
- style.css: Sayfaların CSS kuralları
