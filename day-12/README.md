# Day 12 – İş Başvuru Takip Uygulaması

Bu projede JavaScript kullanarak iş başvurularını takip edebileceğim bir uygulama geliştirdim.

## Özellikler

- Yeni iş başvurusu ekleme
- Şirket, pozisyon, tarih ve başvuru durumu kaydetme
- Başvuruları duruma göre filtreleme
- Başvuruları silme
- Toplam başvuru, mülakat ve teklif sayılarını gösterme
- Verileri Local Storage ile tarayıcıda saklama
- Başvuru durumlarına göre renkli kartlar
- Responsive tasarım

## Kullandığım Teknolojiler

- HTML5
- CSS3
- JavaScript
- DOM
- Local Storage
- JSON

## Öğrendiklerim

- Form verilerini JavaScript ile alma
- Nesne oluşturma ve diziye ekleme
- `filter()` ile kayıtları filtreleme
- Dinamik HTML elemanları oluşturma
- `JSON.stringify()` ve `JSON.parse()` kullanımı
- Verileri Local Storage üzerinde kalıcı hâle getirme
- Kayıtları benzersiz `id` değerleriyle silme
- Form gönderme ve `change` olaylarını yönetme
